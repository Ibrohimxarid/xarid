# Ijro nazorati — регистрация входящих документов и контроль исполнения

Автоматизирует ведение реестра «…HUJJATLAR BOYICHA»: сотрудник больше не перепечатывает реквизиты
и не рассылает документы вручную.

- Документ распознаётся **на ноутбуке** локальной моделью. До подтверждения сотрудником ни файл, ни данные
  не уходят с компьютера.
- После подтверждения запись попадает в **Google Таблицу** (тот же формат, что и Excel-реестр).
  Исполнители получают письмо, а затем напоминания по срокам.
- **Всё бесплатно**: Ollama, Tesseract, открытые модели, Google Таблицы, Apps Script, Gmail.

## Как это работает

```
 Ноутбук сотрудника (без интернета)                         Google (служебный аккаунт)
 ─────────────────────────────────────────────              ─────────────────────────────────
 1. скан/PDF → папка Kiruvchi                               5. строка в реестре (лист «Oktabr 2026»)
 2. IjroNazorati.exe: страницы → OCR (Tesseract)               письмо исполнителям (+ документ)
    → локальная модель (Ollama) → поля                      6. напоминания: за 7, 3, 1 день и в срок;
 3. окно проверки: документ слева, поля справа                 после срока — копия руководителю
 4. «Ro'yxatga olish» → проверка → «Tasdiqlash» ──────────► 7. исполнители пишут в столбец I
    файл и временные данные удаляются с ноутбука                («Ijrosi haqida qisqacha ma'lumot»)
```

| Столбец реестра | Кто заполняет |
|---|---|
| B–G: номер и дата регистрации, исходящий номер, резолюция, срок, краткое содержание | ИИ, проверяет сотрудник |
| H «Ijro holati» | сотрудник (выпадающий список) |
| I «Ijrosi haqida qisqacha ma'lumot» | ответственный исполнитель — **только этот столбец** |

### Правило «ничего не выдумывать»

- Если модель не уверена, поле остаётся **пустым** и подсвечивается жёлтым.
- Номера и даты, которые модель вписала, программа ищет в тексте документа (OCR или текст PDF).
  Не нашла — поле подсвечивается **оранжевым**: значение надо сверить с документом отдельно.
  Так бывает, например, с рукописным штампом.
- Без нажатия «Ro'yxatga olish» и «Tasdiqlash va yuborish» ничего не регистрируется и не рассылается.

## Установка

### 1. Google-часть (один раз)

1. Создайте **отдельный Google-аккаунт** для рассылки, например `ijro.nazorat.xxx@gmail.com`.
   Всё дальше делается под ним.
2. Откройте https://script.google.com → «Новый проект».
   - Перенесите файлы из папки `google-apps-script` (или `apps-script` в репозитории):
     каждый `.gs` — отдельным файлом с тем же именем.
   - Содержимое `appsscript.json`: Project Settings → «Show appsscript.json» → вставьте текст.
   - Вместо ручного переноса можно использовать [clasp](https://github.com/google/clasp):
     `.clasp.json.example` → `.clasp.json`, затем `clasp push`.
3. Выберите функцию `setup` → «Выполнить» → разрешите доступ. В журнале выполнения появятся
   **ссылка на реестр** и **токен**.
4. Откройте реестр, лист «Sozlamalar», и заполните его:
   - сотрудники;
   - корпоративная почта для копий и ответов;
   - почта руководителя для просрочек (если оставить пустой, копии при просрочке не будет);
   - статусы.

   Затем выполните функцию `applySettings`.
5. «Развернуть» → «Новое развёртывание» → тип «Веб-приложение»:
   - **Execute as: Me**, **Who has access: Anyone**;
   - скопируйте URL вида `https://script.google.com/macros/s/…/exec`.

   Доступ защищён токеном из шага 3.

### 2. Ноутбук сотрудника

1. **Ollama** — https://ollama.com/download → установить. Затем в командной строке:
   ```
   ollama pull qwen2.5vl:7b
   ```
   Модель выбирается под ноутбук (см. «Выбор модели» ниже).
2. **Tesseract OCR** — установщик для Windows: https://github.com/UB-Mannheim/tesseract/wiki.
   При установке отметьте языки **Uzbek**, **Uzbek (Cyrillic)**, **Russian**. Без Tesseract программа
   тоже работает, но не сможет сверить номера и даты с текстом документа — они все будут оранжевыми.
3. **IjroNazorati.exe** — на GitHub: вкладка *Actions* → последняя успешная сборка
   «Ijro nazorati — testlar va IjroNazorati.exe» → *Artifacts* → `IjroNazorati-windows`.
   Распакуйте в отдельную папку, например `C:\Ijro`.
4. Запустите `IjroNazorati.exe`. Рядом появятся:
   - `config.yaml` — настройки;
   - `Kiruvchi\` — папка для новых документов;
   - `kontaktlar.xlsx` — список исполнителей;
   - `.ish\` — временные данные.

   Закройте окно программы.
5. В `config.yaml` впишите `remote.url` (URL веб-приложения) и `remote.token` (токен из `setup`).
6. Заполните `kontaktlar.xlsx`. Столбцы:
   - **Ism yoki tashkilot** — как пишется в резолюции: `U.Xoshimova`, `TTPU`;
   - **Email** — несколько адресов через запятую;
   - **Boshqa yozilishlar** — другие варианты написания: `Xoshimova U., Хошимова У.`.
7. Проверка: в командной строке в папке программы выполните `IjroNazorati.exe --check`.
   Все строки должны быть `[OK]`.
8. Автозапуск: `Win+R` → `shell:startup` → положите туда ярлык на `IjroNazorati.exe`.

### 3. Что попросить у IT

- Добавить адрес служебного аккаунта в **белый список** корпоративной почты, иначе письма уйдут в спам.
  Правило пересылки не подойдёт: оно не умеет выбирать исполнителей конкретного документа.
- Разрешить установку Ollama, Tesseract и запуск `IjroNazorati.exe`. Exe не подписан, поэтому Windows
  SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

### 4. Исполнители

Чтобы писать в столбец I, исполнителю нужен Google-аккаунт на его корпоративный адрес. Его можно создать
без Gmail: «Создать аккаунт» → «Использовать существующий адрес электронной почты». Доступ к реестру
выдаётся автоматически при первой регистрации документа (настройка «Ijrochilarga avtomatik ruxsat»).

## Работа сотрудника

1. Положить скан или PDF в `Kiruvchi`. Подходят PDF, JPG, PNG, TIFF; можно несколько сразу.
2. Окно проверки откроется в браузере (адрес `http://127.0.0.1:8765`). Документ появится со статусом
   «O'qilmoqda», затем «Tekshiring».
3. «Ochish»: слева страницы документа (клик — увеличить), справа поля. Заполнить жёлтые, сверить оранжевые.
   Если исполнитель не найден в контактах — вписать email вручную.
4. «Ro'yxatga olish…» → экран с итогом: что уйдёт в реестр и кто получит письмо → «Tasdiqlash va yuborish».
5. Другие кнопки:
   - «Rad etish» — удалить документ без регистрации;
   - «Qayta o'qish» — распознать заново, можно указать другую модель.
6. «Ijro holati» в Google Таблице заполняет сотрудник.

## Напоминания

Приходят в 9:00 по Ташкенту, даже если ноутбук выключен:

- письмо при регистрации;
- за 7 дней — только если при регистрации до срока было больше недели;
- за 3 дня, за 1 день и в день срока;
- на следующий день после срока — одно письмо «Muddati o'tdi» с копией руководителю.

Напоминания прекращаются, когда «Ijro holati» = `Bajarildi` или `Nazoratdan olindi` (настраивается).
Если срок перенесли, исправьте дату в столбце J «Muddat (sana)» — расписание пересчитается.

## Выбор модели

| Ноутбук | Модель в `config.yaml` |
|---|---|
| 8 ГБ ОЗУ, без видеокарты | `qwen2.5vl:3b` или `gemma3:4b` |
| 16 ГБ ОЗУ | `qwen2.5vl:7b` (по умолчанию) |
| 32 ГБ ОЗУ или видеокарта от 8 ГБ | `gemma3:12b`, `qwen2.5vl:7b` |

Таблица ориентировочная. Скорость и точность лучше замерить на своих документах:

1. Сложите в папку 20–30 прошлых документов (копии!).
2. Рядом положите `kutilgan.csv` с правильными ответами, разделитель `;`:
   ```
   fayl;royxat_raqami;royxat_sanasi;chiqish_raqami;ijro_muddati_sana;ijrochilar
   488-PA.pdf;488-PA;2026-10-01;26-2850;2026-10-12;U.Xoshimova, TTPU
   ```
3. Выполните:
   ```
   IjroNazorati.exe --benchmark C:\Ijro\namuna --models qwen2.5vl:7b,gemma3:4b
   ```

Отчёт покажет по каждому полю, сколько значений верных, сколько пустых и сколько **ошибочных**.
Ошибочные — самое опасное, выбирайте модель с наименьшим их числом. Исходные файлы при этом
не изменяются и не удаляются.

## Ограничения

- Локальная модель слабее облачной. Рукописный штамп и резолюцию она часто не прочитает (поле останется
  пустым), а краткое содержание на узбекском иногда придётся править.
- Без видеокарты одна страница может распознаваться от десятков секунд до нескольких минут.
- Gmail отправляет с бесплатного аккаунта примерно 100 получателей в день через Apps Script.
  Если не хватает, нужен аккаунт Google Workspace.
- Сам документ уходит в Google только как вложение письма и только после подтверждения.
  Чтобы не отправлять его вообще, поставьте `send_pdf: false` в `config.yaml`.
- Исполнители видят весь реестр (все строки), но менять могут только столбец I.

## Для разработчика

```
ijro-nazorati/
  apps-script/   Google-часть: реестр, веб-приложение (doPost), письма, напоминания
  local/         программа для ноутбука (Python): ijro/ — код, tests/ — тесты, IjroNazorati.spec — сборка exe
```

```
# Google-часть (Node 20+)
node --test ijro-nazorati/apps-script/tests/*.test.js

# Программа для ноутбука (Python 3.11+)
cd ijro-nazorati/local
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m ijro                         # запуск из исходников
pyinstaller IjroNazorati.spec          # dist/IjroNazorati.exe (собирать на Windows)
```

Exe для Windows собирается автоматически: workflow `.github/workflows/ijro-nazorati.yml` запускает
тесты, собирает exe на `windows-latest`, проверяет его в пустой папке и выкладывает в *Artifacts*.
