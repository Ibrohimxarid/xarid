# Стратегия музея 2027 — оформление Monad

`museum-strategy-2027-monad.pptx` — презентация «Тошкент политехника музейини 2027 йилда ривожлантириш стратегияси», пересобранная в стиле Monad («editorial tech journal on warm parchment»). 20 слайдов, 16:9, полностью редактируемая: текст, таблицы и диаграмма — нативные объекты PowerPoint, картинками остаются только фото, логотип и размытые фоновые пятна.

## Система
- Фон Parchment `#F6F3F1`; тёмные слайды (1, 6, 14) — Off-Black `#242424`.
- Текст `#242424` / `#4E4D4D`, подписи и источники `#797776`, линии `#CECAC8` 1 pt.
- Не больше одного элемента Lake Blue `#2B59D1` на слайд; Periwinkle `#CFDAF5` — одна выделенная карточка. Пастельные цвета только в трёх размытых пятнах (слайды 1, 8, 14).
- Шрифты: Cambria (заголовки, крупные цифры, без жирного, −2 %) и Consolas (весь остальной текст). Тема оформления содержит только цвета палитры.
- Поля 0,6″, отступы 0,3″/0,5″; таблетка раздела слева вверху, номер «NN / 20» справа внизу; в PowerPoint заведены разделы.

## Пересборка
```
python3 build/mkqafont.py      # служебные шрифты для замера строк (в файл не попадают)
python3 build/build.py <исходник.pptx> <выход.pptx>
```
Весь текст слайдов берётся из исходника дословно, заметки докладчика копируются без изменений.
